A modern and responsive **E-Commerce Shopping Website** built using **HTML, CSS, and JavaScript**. This project demonstrates the core functionality of an online shopping platform, including product browsing, shopping cart management, and checkout.

---

# 📖 Overview

ShopEasy is a beginner-friendly e-commerce website that simulates the shopping experience of popular online stores. Users can browse products, add items to the cart, manage quantities, and complete a simple checkout process.
